### The Calendar has its own address

- **Before (3.x)**: the *Calendar* screen opened at `/creneaux`, after what it lists.
- **After (4.0)**: it opens at **`/calendrier`**, the name the menu and the palette give it. The former address `/creneaux` redirects to the new one and keeps every parameter (`?edit=`, `?onglet=`…): a bookmark or a link already sent keeps working. The redirect goes away in 5.0. The API routes (`/api/creneaux`) do not change.
- **What you do**: nothing. If you keep bookmarks or internal documentation links to `/creneaux`, replace them with `/calendrier` before 5.0.
