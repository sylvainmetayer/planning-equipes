### One days-in-a-row rule

- **Before (3.x)**: two rules for one cap, `maxJoursConsecutifsTravailles` (weighted, on) and `maxJoursConsecutifsTravaillesDur` (hard, off by default). An edition that wanted a blocking cap switched the second one on. Under the hard form, the Timefold engine built the first plan day by day, in calendar order.
- **After (4.0)**: a single rule, `maxJoursConsecutifsTravailles`, whose level is chosen like that of the other organisation rules: preference (the default, at the weight it had) or mandatory. The catalogue loses one rule. The calendar construction order is withdrawn: construction goes by scarcity, on both engines.
- **What you do**: nothing for stored editions. Migration `V162` makes the rule **mandatory** in an edition that had switched the hard form on (and switches it back on if the weighted form had been switched off); otherwise the rule keeps the level, weight and switch of the weighted form, and **no score moves**. An edition that had both forms on keeps only the mandatory rule, which no longer also costs medium points. The old name `maxJoursConsecutifsTravaillesDur` is read until 5.0, with a warning, as a level: in a YAML scenario, `activees` reads it as `niveaux: {maxJoursConsecutifsTravailles: OBLIGATOIRE}`; through `PUT /api/constraints/maxJoursConsecutifsTravaillesDur` or `modifier_contrainte`, switching it on makes the rule mandatory, switching it off makes it a preference again; a weight sent under that old name is refused (400), since it was a hard weight. `planning.constraint-weights.maxJoursConsecutifsTravaillesDur` is no longer read: remove it.
- **If you solve with `SOLVER_ENGINE=timefold`**: an edition that holds the rule mandatory loses the calendar order. Measured on the versioned scenarios, the final plan costs 6 to 8% more medium on `festival-realiste-canicule` and `scenario-complet`, and up to 35% on `gamme-20` and `gamme-25`, for the same budget. The direct engine, the default one, is not affected: it already built by scarcity alone ([ADR 0118](repo:docs/decisions/0118-une-seule-regle-de-jours-d-affilee-a-niveau-reglable.md)).
