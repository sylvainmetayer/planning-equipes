# Documentation

Planning Équipes calculates the schedule of an event, you review it and you publish it. Pick the part that matches what you have to do.

## Where to start

- You organise the team of an event and you are discovering the application: read [the thread of an edition](regles/fil-d-une-edition.md), then [prepare your first edition](regles/preparer-edition.md).
- You want to run a first solve: [solve the schedule](regles/calculer-planning.md), then [publish it](regles/publier-planning.md).
- You are installing the application on your server: [install the application](installer/installation.md), then [fill in the legal notice](installer/mentions-legales.md), without which it does not start.
- You develop or audit the project: read [the stack and how the code is split](comprendre/vue-d-ensemble.md), then [run the application locally](comprendre/demarrer.md).
