# Documentation

Planning Équipes calcule le planning d'un événement, vous le relisez et vous le publiez. Choisissez la partie qui correspond à ce que vous avez à faire.

## Par où commencer

- Vous organisez l'équipe d'un événement et vous découvrez l'application : lisez [le fil d'une édition](regles/fil-d-une-edition.md), puis [préparez votre première édition](regles/preparer-edition.md).
- Vous voulez lancer un premier calcul : [calculer le planning](regles/calculer-planning.md), puis [le publier](regles/publier-planning.md).
- Vous installez l'application sur votre serveur : [installer l'application](installer/installation.md), puis [toutes les variables d'environnement](installer/variables-environnement.md).
- Vous développez ou vous auditez le projet : [l'architecture](comprendre/architecture.md) donne la vue d'ensemble.
