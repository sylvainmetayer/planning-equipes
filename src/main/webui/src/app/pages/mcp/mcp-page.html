Se connecter sans abonnement payant

Le connecteur MCP est souvent réservé aux offres payantes. Ce qui départage les chemins gratuits, c'est l'authentification que le client sait présenter.
  • Le Chat (Mistral), gratuit — connecteur MCP personnalisé, clé en Authorization: Bearer. L'instance doit être joignable depuis Internet.
  • Claude Desktop, gratuit — par le pont mcp-remote, qui envoie la configuration ci-dessus telle quelle. L'instance peut rester privée.
  • VS Code avec Copilot Free — mode agent et MCP inclus, n'importe quel en-tête, sous plafonds mensuels.
  • Claude sur le web — connecteur personnalisé possible en gratuit, mais son formulaire ne sait faire qu'OAuth : la clé n'a pas de case où se mettre.
  • ChatGPT — les connecteurs personnalisés sont hors du plan gratuit.
