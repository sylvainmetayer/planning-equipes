Import des animateurs (CSV)

Déposez le tableur de vos bénévoles, exporté en CSV, dites quelle colonne est quel champ, lisez ce que l'import ferait, puis validez. Rien n'est écrit avant cette validation : tant que vous n'avez pas cliqué sur « Importer », cet écran ne fait que lire votre fichier. Le fichier reste en mémoire, il n'est jamais enregistré sur le serveur.

1. Le fichier Format CSV uniquement — séparateur virgule, point-virgule ou tabulation, reconnu tout seul. Un classeur .xlsx doit d'abord être ré-enregistré en CSV depuis votre tableur.

La date de naissance est obligatoire pour créer une fiche : tout le régime mineur / majeur en dépend. Les compétences, les souhaits et les jours d'indisponibilité peuvent tenir plusieurs valeurs dans une même cellule, séparées par « | ». Une compétence s'écrit « typologie » ou « typologie:REFERENT ».
